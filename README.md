## Getting started: a practical workflow

1. Download the Windows ZIP from the latest GitHub Release and extract it.
2. Choose the region you are exploring and make a short list of collectible types you still need.
3. Record completed discoveries as you go, including any key items needed for later access.
4. Before leaving the region, cross-check entries using a source that matches the current game build.
5. Use the same checklist during a post-story cleanup instead of restarting the search from scratch.

**Do not rely on one fixed “total collectibles” number.** Major published walkthroughs use different category definitions or have been revised after updates. Compare the type of item and the region, not only a global counter.
